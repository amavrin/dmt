# Математическая модель движения автомобиля

Документ описывает упрощённую математическую модель автомобиля, используемую в проекте.

Цель модели:

* предсказуемое и понятное поведение;
* визуализация геометрии маневрирования;
* минимальная сложность реализации;
* отсутствие сложной физики.

Для MVP используется кинематическая модель типа **Bicycle Model**.

---

# Системы координат

## Мировая система координат

Используется двумерная плоскость:

* X — горизонтальная ось;
* Y — вертикальная ось.

Все объекты сцены описываются в мировых координатах.

---

## Локальная система автомобиля

Автомобиль имеет:

* позицию;
* направление;
* локальную систему координат.

Начало координат:

* центр задней оси.

Ось:

* +X — вперёд;
* +Y — вправо.

---

# Представление автомобиля

Автомобиль описывается следующими параметрами:

```cpp
struct CarState
{
    Vec2 position;      // центр задней оси
    float heading;      // угол автомобиля
    float steering;     // угол поворота передних колёс
};
```

# Bicycle Model

Для MVP используется упрощённая модель:

* одна передняя ось;
* одна задняя ось;
* передние колёса имеют общий steering angle;
* задние колёса фиксированы.

---

# Основное уравнение поворота

Угловая скорость автомобиля:

```text
angularVelocity = v / L * tan(steeringAngle)
```

где:

* v — линейная скорость;
* L — колёсная база;
* steeringAngle — угол поворота колёс.

---

# Обновление состояния

## Линейное движение

```text
x += cos(heading) * v * dt
y += sin(heading) * v * dt
```

---

## Поворот

```text
heading += angularVelocity * dt
```

---

# Радиус поворота

Радиус траектории:

```text
turnRadius = L / tan(steeringAngle)
```

Особенности:

* чем больше steering angle, тем меньше радиус;
* при steeringAngle = 0 автомобиль движется по прямой.

---

# Центр поворота

Instantaneous Center of Rotation (ICR):

```text
ICR находится на расстоянии turnRadius
от центра задней оси.
```

Используется для:

* визуализации центра поворота;
* объяснения движения автомобиля.

---

# Траектория

## Историческая траектория

Хранится массив позиций:

```cpp
std::vector<Vec2> trajectory;
```

Используется для:

* отображения пройденного пути;
* анализа манёвра.

---

## Прогнозируемая траектория

Вычисляется пошаговой симуляцией:

```text
for t in futureTime:
    simulateStep(dt)
```

Результат:

* массив будущих положений автомобиля.

---

# Swept Path

Swept Path — область, занимаемая автомобилем во время движения.

Используется для:

* визуализации габаритов;
* оценки возможности проезда;
* обучения парковке.

---

# Передняя и задняя траектории

Важно отображать:

* траекторию передней оси;
* траекторию задней оси.

Причина:

* задняя ось "срезает" траекторию;
* это ключевая особенность маневрирования.

---

# Контур автомобиля

Контур автомобиля описывается полигоном.

Пример:

```cpp
std::vector<Vec2> carPolygon;
```

---

# Преобразование координат

Для преобразования локальных координат автомобиля в мировые:

```text
worldPoint =
    position +
    rotate(localPoint, heading)
```

---

# Collision Detection

Для MVP достаточно:

* polygon intersection;
* SAT (Separating Axis Theorem).

Физический движок не требуется.

---

# Ограничения модели

Текущая модель:

* не учитывает инерцию;
* не моделирует сцепление;
* не учитывает занос;
* не моделирует подвеску;
* не моделирует дифференциал.

Это сознательное упрощение.
